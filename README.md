# PLP Python Week 8: Final Project — Personal Mini-Toolkit

A comprehensive, menu-driven Python application bringing together core programming fundamentals including variables, conditionals, while/for loops, dynamic lists, and friendly f-string formatting.

## Project Files
- `toolkit_plan.txt`: The initial design blueprint outlining features, menu layout, and programming concepts.
- `toolkit.py`: The core script implementing the menu loop and three functional interactive tools.
- `screenshots/`: Folder containing verification screenshots of the menu, invalid choice handling, and all tools running.

## How to Run
1. Make sure Python 3 is installed on your system.
2. Open your terminal in the project directory.
3. Run the application:
   ```bash
   python toolkit.py
